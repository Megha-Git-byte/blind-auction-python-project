# Blind Auction Python Project

A command-line secret auction program built in Python. Multiple users can enter their names and private bids without seeing previous offers, and the program automatically determines the highest bidder.

## How It Works
1. Prompts each bidder for their name and bid amount.
2. Stores the bids inside a Python dictionary.
3. Clears the console screen between bidders to keep bids private.
4. Compares all bids once everyone has entered their amount and announces the winner.

## How to Run
1. Make sure both `main.py` and `art.py` are in the same folder.
2. Open your terminal and run:
   ```bash
   python main.py
   ```
